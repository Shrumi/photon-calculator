# Демо-версия: калькулятор прайса «ФОТОН»

Десктоп-приложение для администратора фото-салона. Это **демо** полной версии:
полный функционал на **3 минуты**, затем — окно активации ключом.

## Возможности

- **Умный поиск услуг** по первым двум буквам — любая раскладка (латиница
  автоматически превращается в кириллицу) и регистр: `пе`/`gt` → «Печать фото».
- **Чек**: выбор услуги стрелками, количество с клавиатуры, мгновенный пересчёт.
- **Кассовый отчёт смены**: наличные / карта / общая сумма — Z-отчёт за секунды.

## Демо-режим и активация

- 3 минуты работы с момента первого запуска (время накопительное —
  перезапуск демо не сбрасывает).
- По истечении — окно блокировки с вашим **Machine ID**, кнопкой
  «Запросить ключ» (открывает почтовый клиент с готовым письмом) и полем
  ввода ключа.
- Ключ активирует полную версию на этом ПК.

## Для владельца (генерация ключей)

```bash
pip install -r requirements.txt
python keygen.py --machine XXXX-XXXX-XXXX   # ключ под Machine ID клиента
python aggregator.py                        # IMAP-агрегатор: читает запросы
```

Переменные окружения для агрегатора:

- `PHOTON_IMAP_USER` — `shrumi@yandex.ru`
- `PHOTON_IMAP_APP_PASSWORD` — [пароль приложения Яндекса](https://id.yandex.ru/security/app-passwords)

Агрегатор читает непрочитанные письма с темой **«Запрос ключа ФОТОН»**,
достаёт Machine ID и печатает готовый ключ для ответа клиенту.

## Технологии

Python 3.12 · FastAPI + Uvicorn (локальный сервер) · HTML/JS UI ·
PyInstaller (onefile ~34 MB, без внешних зависимостей на машине клиента).
Лицензии — оффлайн HMAC-SHA256, без обращения к внешним серверам.

## Запуск из исходников
